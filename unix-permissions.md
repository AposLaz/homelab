| Number | Permission | Meaning                |
| -----: | ---------- | ---------------------- |
|    `0` | `---`      | no access              |
|    `1` | `--x`      | execute only           |
|    `2` | `-w-`      | write only             |
|    `3` | `-wx`      | write + execute        |
|    `4` | `r--`      | read only              |
|    `5` | `r-x`      | read + execute         |
|    `6` | `rw-`      | read + write           |
|    `7` | `rwx`      | read + write + execute |
